Helm generates a RANDOM password per install. cub renders deterministically and ships an auth Secret in out/secrets/ — but for these default bases the value is FIXED (identical across namespaces, committed in the package, e.g. `confighub-redis-password`). That is a shared, well-known default credential, not a generated one — convenient for demos, a footgun deployed unchanged. Bases named `generated-passwords` that ship a fixed value are misleadingly named.

Overall: watch — cub renders deterministically (good), but a fixed default password is shared across all installs (footgun).
