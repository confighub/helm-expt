# Workshop assistant UX rounds

Bounded local missions used fresh gpt-5.6-luna participants with low reasoning,
supplied pinned setup and reviewer checks of retained artifacts and explanations.
The reviewer owns interpretation and fixes. These are small distinct cohorts,
not population pass rates, first-use benchmarks or live deployment evidence.

## Changes supported by the findings

Publish the exact Redis lookup JSON, bind it to the CLI in a verifier, name the
GitOps shop selection on the platform page, and link complete missions directly
from the homepage. Complete the Compose Guide's copyable AI task with the
post-refusal recovery sequence already present in its human instructions.
The last prompt edit is structurally gated and passed a separate fresh
copy-and-paste regression pair.
