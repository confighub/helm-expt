Run Safety

Run live parity reruns serially. Do not run two live parity commands at the same time from different terminals or agents. The live harness creates and prunes parity-owned kind clusters and related local resources; concurrent runs can delete each other's in-flight cluster and produce a false infrastructure failure.

If several rows need reruns, run one command, let it finish, inspect the receipt, regenerate the relevant summary, then move to the next row.

Some pinned public chart versions remain available from OCI even when the classic Helm repository index no longer exposes them. The generated commands include an explicit --repo-url override for those rows. This keeps the rerun command faithful to the locked chart/version without changing the recipe.
