Extension slots are Helm inputs that can inject raw manifests, templated snippets, config blocks, sidecars, extra volumes, or chart-specific config files. They are useful, but a populated slot changes the install shape. The supported catalog route is to keep them empty or controlled in the first base, then create a reviewed cub installer base when a slot is populated.
