Pick a model variant

Every variant is flatten-with-routes. Its objects are kept as they are, and its routes name the NIM Operator, the image pull Secret, the model API key Secret and the model storage that come first.

NVIDIA gates the images and the model weights. The Catalog did not pull them, does not hold them and never redistributes them.
