What this command does. cub installer is a released, open-source plugin for the cub CLI. cub installer setup pulls a catalog package and writes its Kubernetes files locally, leaving delivery to kubectl, Argo CD or Flux.

Before you run it. Install the cub CLI. Public catalog packages are open to anyone.

Evidence

Check the result and the limits

A tested example names its source, its version, and the objects it produces, then records which checks ran against it. The page says which checks did not run, and known gaps stay visible.

Four questions sit behind every result. Each one needs its own input and can only claim its own kind of answer, so we keep them apart rather than rolling them into a single verdict.

QuestionWhat it needsWhat it can tell you
What do I have?Source files, an OCI, or a snapshot.Source identity, contents, and differences you can see locally.
What will it produce?The source-native processor and its recorded choices.The exact object set, and its identity.
Can this destination accept it?The candidate, plus current facts from the named destination.API, CRD, Secret, policy and credential readiness for that destination.
Did it work?The exact delivered revision, deployed, with live evidence.Controller, workload, drift and rollback results that were actually checked.

A missing prerequisite is reported as blocked or not-run. It is a different result from a configuration that failed, and we keep the two labelled apart.
