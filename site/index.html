How It Works

1. Render

Helm output is captured as a cub installer package and compared with regular Helm output.

2. Vary

Supported variants make common choices explicit: default, existing Secret, no CRDs, local storage, ingress, and similar paths.

3. Prove

Receipts record equivalence, scans, gates, ConfigHub upload, local live evidence, and latest-version promotion readiness.
