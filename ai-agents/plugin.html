What the plugin records and what it never records

Hooks run locally on your machine and write signed entries to ~/.confighub/agent-changes. Nothing leaves your computer unless you opt in.

Recorded locally

Config keys, CLI changes, and prompts

  • Changed keys in .env, Compose, Terraform, GitHub Actions, Kubernetes YAML, Helm values, and Kustomize files.
  • State-changing CLI commands (vercel, fly, aws ssm, kubectl, helm, terraform, cub) and MCP tool calls.
  • The prompt you gave the agent and the reason it stated, signed on disk.
Never recorded

Secrets, passwords, and raw command output

  • Anything matching a password, API key, token, or credential connection string is skipped.
  • Full file copies and raw command stdout are not stored in the journal.
  • Ordinary code edits outside config files stay untouched so coding speed does not change.

Zero-hub guardrails for teams and pull requests

You can adopt four practical safeguards before you ever start a hub.

Emergency stop

Pause every Claude Code session at its next tool call with one file on disk.

touch ~/.confighub/halt

Pull-request review comments

Set CUB_MINI_RECORD_IN_REPO=1 and add the GitHub Action so every PR lists changed settings and why they changed.
