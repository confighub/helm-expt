What’s recorded, privacy & how to delete it

Hooks run locally on your machine using a prebuilt binary wrapped by the MIT-licensed plugin launcher, writing signed entries to ~/.confighub/agent-changes. No telemetry leaves your computer unless you opt in.

Recorded locally

Config keys, prompts & 30-day first-run backfill

  • Supported edits: Changed keys in .env, Compose, Terraform, GitHub Actions, Kubernetes YAML, Helm values, and Kustomize files, plus state-changing CLI commands (vercel, fly, aws ssm, kubectl, helm, terraform, cub) and MCP tool calls.
  • Quoted prompts: The request you gave the agent and the reason it stated, signed on disk.
  • First-run 30-day transcript read (Claude Code): On first use in a folder, the plugin reads the last 30 days of local Claude Code session transcripts for that folder so your very first chat already knows why recent settings changed before you installed the plugin.
Redacted, skipped & easy to wipe

Credentials, off switches & deletion

  • Credential redaction: Values matching password, API key, token, or credential connection-string patterns are redacted rather than stored in plain text (pattern-based—see how it works).
  • No raw dumps: Full file copies and raw command stdout are not stored; ordinary code edits outside config files are skipped.
  • Turn off or delete anytime: Pause hooks with touch ~/.confighub/halt, silence hub tips with CUB_MINI_TIPS=0, wipe a folder’s record with confighub mini changes --forget, or uninstall in one command.
