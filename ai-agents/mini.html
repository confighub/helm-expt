Safe previews and production gates on your laptop

ConfigHub Mini bundles the ConfigHub server, PostgreSQL, and cub as ordinary user processes in ~/.confighub. Your agent experiments freely in preview and staging while production waits for your terminal approval.

How one app lives in Mini Hub

Connecting an app does not rewrite your repo files. ConfigHub creates three copies of its settings and an optional isolated preview, plus a scoped key for the agent.

Shared source

app-base

Shared settings and starter defaults, each with a written reason. Changes start here once.

Agent can update

preview

A running local copy on its own port that survives across chats while leaving your usual app alone.

Agent can update

app-staging

Takes base changes right away so your agent can verify behavior before proposing to live.

Owner approves

app-live

Agent proposes a change order on its scoped key; the hub refuses self-approval until you approve.

Two ways to start using Mini Hub

You do not have to pre-install a server. Ask for a durable preview in your app folder, or download the standalone package directly.

Opt-in from chat

Ask for a preview you can reopen tomorrow

In a local Node app reading .env, ask in plain words:

Try "Evening collection" as the heading. Keep the usual app as it is. I'd like to open the preview again tomorrow.

Say yes when the plugin offers to attach the app. First use downloads the 52 to 77 MB package and starts the local hub on 127.0.0.1. Existing app preview guide.

Explicit CLI

Attach any repo or run in CI and sandboxes

Works with .env, Compose, Terraform, and Kustomize repos, or inside a disposable CI job with one hub per run.

cub mini install
cub mini adopt . --component myapp
cub mini waiting

Install Mini & checksums · CI & sandboxes

Review, approve, refuse, or roll back

The agent proposes changes using its own scoped key. You inspect and decide in your own terminal using exact revision IDs.

# See pending production proposals and exact diffs
cub mini waiting

# Approve one exact revision with a note
cub mini approve api-base/upload-20261112-055043-twx5 --note "Checked for Friday sale"

# Or refuse with a reason so the agent does not repeat it
cub mini refuse api-base/upload-20261112-055043-twx5 --reason "Keep 2 replicas off-peak"

# Propose an atomic rollback to the prior revision
cub mini rollback api-live --change-order api-base/upload-20261112-055043-twx5 --reason "Revert sale limit"
No lock-in and a clean exit ramp. Your original files are never modified during adopt. At any point you can export every setting back to plain files and stop or remove the local hub. Going back and uninstalling · Approvals detail.
