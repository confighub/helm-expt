Starters and composable recipes

A starter is a versioned YAML file of default settings, guardrails, and plain-English reasons. Unlike a copy-once template, apps stay linked to their starter so shared fixes reach every app while per-app overrides stay untouched.

Add your own starter or delivery plugin

You are not limited to the starters above. A starter is one YAML file of defaults, rules, and reasons.

Write a 1-file YAML starter

Save this example as team-api.yaml. It gives a Node API a ten-second timeout. The author guide shows how to check it.

starter: team-api
version: 1
about: A Node API that reads its settings from .env.
after: [web]
looks_for:
  files: [package.json, .env]
owns: [API_]
defaults:
  - key: API_TIMEOUT_SECONDS
    value: "10"
    reason: Bound an API call so a slow dependency frees the worker after ten seconds.
wires:
  approval: live
