Honest security boundaries

ConfigHub governs configuration stored in the hub and delivered from it. Know these three boundaries before relying on it in production.

Boundary 1

Direct cloud credentials bypass the hub

If an agent also holds direct write credentials to your cluster, Vercel, Fly, or AWS account, it can bypass the hub. Keep production write keys out of the agent's environment.

Limiting what an agent can reach

Boundary 2

Tamper-evident signed records

Journal entries are cryptographically signed and verifiable with cosign or SPIFFE workload identities. Lock down writes to ~/.confighub/agent-changes in sandbox settings.

Signed records guide

Boundary 3

What we do not claim

Recording is local and offline; the hub is not a secret vault or OS kernel sandbox (pair with Vault or nono/containers for those layers).
