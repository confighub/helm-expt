Everyday commands

Claude Code slash commands

  • /confighub:changes — list recorded config edits and their prompts.
  • /confighub:why NAME — show every change to one setting and why.
  • /confighub:inventory — list what the repo deploys and how.
  • /confighub:checks — control MCP write checks (log, warn, repeats, ask).
  • /confighub:permissions — show what agents may run without asking.
  • /confighub:staging — give the current app staging, live, and approvals in Mini Hub.
  • /confighub:to-hub — copy local plugin records into a hub.
  • /confighub:start-from APP — start a new app inheriting from an existing app.

cub mini terminal commands

  • cub mini install — start the installed local hub on 127.0.0.1.
  • cub mini adopt FOLDER — connect an app's settings without modifying files.
  • cub mini upload FOLDER --variant V — push changes (staging updates, live proposes).
  • cub mini set — set one value in one copy with a written reason.
  • cub mini waiting — inspect pending production orders and exact diffs.
  • cub mini approve ID --note "Why" / cub mini refuse ID --reason "Why" — owner decision.
  • cub mini rollback APP-live --change-order ID --reason "Why" — propose restoring the earlier values.
  • cub mini secret set — store a secret readable by runtime, hidden from agent keys.

How each cub mini verb maps to plain cub

Plain-English glossary

WordWhat it means
HubThe ConfigHub server that holds revisions, reasons, and approvals: either a free local Mini Hub on 127.0.0.1 or a shared team hub.
BaseThe shared settings an app starts from. Make a shared change once in the base so staging and live inherit it cleanly.
Copy (Variant)One environment's settings (preview, staging, or live) derived from the base while keeping its own overrides.
StarterA versioned YAML file of team defaults, rules, and written reasons that multiple apps stay linked to.
Change orderA proposed change to production created by an agent's scoped key that waits for a named human owner's approval.
