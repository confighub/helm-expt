# Top100 Status Model

The top20, top100, and top500 views are not the same claim.

Top20 is the strongest curated catalog slice. It has recipes, package artifacts,
variants, receipts, local/live evidence, and production-scope decisions for
selected bases.

Top100 is the expansion surface. Some charts are ready to try, some need target
prerequisites, some need operator review, and some need better base variants
before they are good product choices.

Top500 is planning and market analysis. It helps decide where the catalog should
go next; it is not the same as a proof-backed supported catalog.

Use the generated matrix and dashboard for current status. Do not copy counts
from those files into prose unless a verifier keeps the prose fresh.
